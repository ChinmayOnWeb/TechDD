## Provenance and methodological concerns

- The old pipeline used `date.today()` for open listed windows. A reproducible
  panel needs one frozen build end; the manifest intentionally refuses to infer it.
- Live repository HEADs move. A remote HEAD observation is not a sufficient build
  lock; only the checked-out HEAD recorded with completed metrics is authoritative.
- SEC CompanyFacts is mutable as new filings arrive. Raw payload preservation is
  necessary even though the endpoint is currently reachable.
- GitLab's GitHub mirror is not an acceptable substitute. The recovery manifest
  and workflow use the real GitLab upstream.
- Headline price series must not be silently substituted or spliced. CRSP remains
  required here; the pre-existing Stooq path is not used to manufacture recovery.
- The full metric scan is intentionally expensive because changing to lite mode
  would alter the frozen Part A metric definitions. No such change was made.
